 # Smart Automated Library & Performance Analytics Engine

A modular Python command-line application developed for the CSE1021 course evaluation project. The application manages library catalog records using tuples, lists, and dictionaries, generates security credentials, and benchmarks algorithm search efficiency trade-offs.

## Project Structure
- `main.py`: Interactive CLI runner and main entry point.
- `library_core.py`: Catalog management, book tuples, and dictionary indexing.
- `security_utils.py`: Pseudo-random card ID generation and prime security key checks.
- `benchmark_engine.py`: Benchmark suite comparing O(N) list search vs. O(1) dictionary lookup.

## Requirements
- Python 3.8+ (Uses built-in standard libraries only).
